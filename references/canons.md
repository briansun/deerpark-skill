# 藏經代碼與收錄範圍

CBETA 經號 = 藏經代碼（大寫字母）+ 編號（通常補零到 4 位，可帶字母尾碼），如 `T0235`、`X0001`、`ZW0073c`、`JB044`、`N0004`。
在 deerpark 上，經號區分大小寫、必須補零：`T0235` 正確，`t0235` / `T235` 都會 404。

## 分類（category）

按經、律、論、宗派、史傳順序：

- 經：阿含部、本緣部、般若部、法華部、華嚴部、寶積部、涅槃部、大集部、經集部、密教部
- 律：律部
- 論：毘曇部、中觀部、瑜伽部、論集部
- 宗派：禪宗部、淨土宗部
- 史傳 / 工具：史傳部、事彙部
- 其他：敦煌寫本部、南傳大藏經部、新編部

分類頁：`https://deerpark.app/cbeta/category/{分類名}`。`/api/search/title` 與 `/api/v1/work` 的回應都有 `category` 欄位；`/api/v1/allworks` 沒有。

## 行號（lb）格式

CBETA 行號如 `T08n0235_p0748c15`：

| 片段 | 意義 |
|------|------|
| `T08` | 大正藏第 8 冊 |
| `n0235` | 經號 0235 |
| `p0748` | 第 748 頁 |
| `c` | 第 3 欄（a/b/c） |
| `15` | 第 15 行 |

學術引用慣例：`T08, no. 235, p. 748c15` 或 `CBETA, T08, no. 235, p. 748, c15`。
行號只存在於 HTML 版（`/api/v1/html`）的 `<span class="lb">` 中，Markdown 版已移除。
